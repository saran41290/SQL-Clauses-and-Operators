# SQL Clauses and Operators

This repository contains beginner-to-intermediate SQL query practice using a small e-commerce database.

## Project Overview
The repository is designed to strengthen SQL filtering and query-writing skills using common clauses and operators that are frequently used in analysis and reporting.

## Topics Covered
- DISTINCT
- Column aliasing with `AS`
- WHERE clause
- Comparison operators
- Arithmetic operators
- Logical operators
- IS NULL / IS NOT NULL
- IN / NOT IN
- BETWEEN / NOT BETWEEN
- LIKE / NOT LIKE
- Mixed query conditions

## Database Used
ECommerceDB

## Files Included
- `01_problem_statements/`
- `02_schema_and_setup/`
- `03_solutions/`

## Key Learning Outcomes
- Built confidence in writing filter conditions
- Practiced combining multiple conditions
- Learned pattern matching and range filtering
- Improved SQL readability with aliases
